How to Export High-Quality Logo Images

Follow these steps to save the DeepOMAP logo in high-resolution:

  1. Click on any of the export buttons above to generate a PNG of the desired size
  2. Right-click on the generated image and select "Save Image As..."
  3. Choose a location on your computer to save the image
  4. For highest quality, use the SVG option which is resolution-independent

The SVG file can be opened and further edited in vector graphics software like Adobe Illustrator, Figma, or Inkscape.
